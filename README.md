# DecoraTV Studio

Premium TV concealment simulator and designer frame customizer.

## Features
- **Real-time 3D-Style Visualization:** Layered rendering of frames, liners, and art.
- **Dynamic Catalog:** Automatic loading of materials from database.
- **Glassmorphism UI:** Premium aesthetic with blur effects and smooth transitions.
- **Quote System:** Automated inquiry capture and management.
- **Selection Tracking:** Real-time display of Frame, Liner, and Artwork IDs for easy reference.

## Technical Stack
- **Backend:** PHP 8+ with PDO.
- **Database:** SQLite 3 (Hybrid support for MySQL).
- **Frontend:** Vanilla JS, Tailwind CSS, Font Awesome.
- **Optimization:** Automatic image resizing and compression for high performance.
